# 🧭 Python Habit Tracker

Yksinkertainen komentoriviohjelma (CLI), jolla voit seurata päivittäisiä tapojasi ja nähdä kehityksen helposti.

---

## 🔧 Ominaisuudet

✅ Lisää uusia merkintöjä (päivä, tapa, arvo)  
✅ Listaa kaikki merkinnät aikajärjestyksessä  
✅ Näytä yhteenveto tottumusten määrästä  
✅ Seuraa peräkkäisiä päiviä ("streak")  
✅ Näytä viimeisen 7 päivän merkinnät  
✅ Tallentaa automaattisesti paikalliseen JSON-tiedostoon
